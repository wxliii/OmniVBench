01 / CONTRIBUTIONS

OmniVBench: A Benchmark and Large-Scale Dataset for Omni Reference-to-Video Generation

01

Comprehensive R2V benchmark

OmniVBench covers diverse reference conditions and compositional requirements with 813 evaluation cases and 12,207 factor-grounded checklist items, enabling fine-grained evaluation of reference utilization.

02

Industrial-scale Omni-R2V Dataset

We construct and release a large-scale public R2V training resource with approximately 380K processed samples across 7 task families, built primarily from professional video footage and supported by reusable, task-specific construction pipelines.

03

Capability analysis across R2V models

Evaluation of representative open- and closed-source models reveals substantial capability gaps across task families and a clear discrepancy between reference preservation and instruction realization.

Coverage, construction, and instructions.

01 / CONSTRUCTION

Task-specific pairing

Cross-pair matching finds references with the required identity or style relationship. Inverse construction derives task-relevant references from targets. Complementary roles are combined for multi-reference tasks.

02 / INSTRUCTIONS

Explicit reference roles

References and targets are captioned separately, then task-specific rules form instructions that identify each reference and its intended entity or visual factor.

03 / COVERAGE

Live action, 2D and 3D

Image and video conditions are drawn from live-action footage as well as 2D and 3D animation, so each reference family spans more than one visual domain.
